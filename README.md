# Ripeto（リピト）サポートページ

演奏会・発表会などの本番に向けて、練習を記録するアプリです。

---

## このアプリについて

演奏会などのゴールを定めて、練習の記録を残すアプリです。  
繰り返し練習することから、「Ripeto（リピト）」と名付けました。

練習箇所ごとに星が積み上がっていく達成感と、本番までの残り日数を見ながら、毎日の練習を続けるためのサポートをします。

---

## 主な機能

- **ゴール管理** — 演奏会・発表会など本番の日程を登録し、残り日数をカウントダウン
- **曲目・練習箇所の管理** — 曲ごとに練習箇所を細かく登録できます
- **練習記録** — 1回練習するたびに記録。メモも残せます
- **星の成長** — 練習回数に応じて星が進化します（練習中 → スター → キラスター → メダル）
- **ダッシュボード** — 総練習回数や本番までの日数を一覧で確認

---

## 使い方

1. **ゴールを追加する** — 本番のタイトルと日付を登録します
2. **曲目を追加する** — ゴールに練習する曲を追加します
3. **練習箇所を追加する** — 曲の中で練習したい箇所を登録します（例：「冒頭8小節」）
4. **練習を記録する** — 練習箇所をタップして「記録」ボタンを押すだけ。メモも添えられます
5. **ダッシュボードを確認する** — 本番まであと何日か、どれだけ積み上げたかを確認できます

## よくある質問

**Q. データはどこに保存されますか？**  
クラウド（Firebase）に保存されます。最初は匿名でご利用いただけます。Google / Apple アカウントと連携することで、機種変更後もデータを引き継ぐことができます。

**Q. オフラインでも使えますか？**  
はい。オフライン時でも練習記録を残せます。ネット接続が回復した際に自動で同期されます。

**Q. プレミアムとは何ですか？**  
買い切りで広告を完全に非表示にする機能です。一度購入すれば、機種変更後も「購入を復元する」から無料で再適用できます。
